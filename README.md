## 1. Project Title
**Binary Classification Using Logistic Regression**

## 2. Problem Statement
The aim of this activity is to develop a machine learning model using Logistic Regression to classify breast cancer tumours into two categories: Malignant and Benign.

## 3. Dataset Description
- **Dataset:** Breast Cancer Wisconsin Dataset
- **Source:** Scikit-learn built-in dataset
- **Dataset link:** https://scikit-learn.org/stable/datasets/toy_dataset.html
- **Target Variable:** Tumour classification
- **Classes:**
  - 0 – Benign
  - 1 – Malignant
- **Features:** The dataset contains 30 numerical features related to tumour characteristics.

## 4. Objective
- To understand binary classification using Logistic Regression.
- To inspect and preprocess the dataset.
- To divide the dataset into training and testing sets.
- To train a Logistic Regression model.
- To evaluate the model using classification metrics.
- To understand the confusion matrix and ROC curve.

## 5. Tools and Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 6. Implementation Steps
1. Imported the required Python libraries.
2. Loaded the Breast Cancer Wisconsin dataset.
3. Inspected the dataset and checked missing values.
4. Analysed the distribution of target classes.
5. Split the dataset into training and testing sets using stratified sampling.
6. Applied feature scaling using StandardScaler.
7. Trained the Logistic Regression model.
8. Predicted the test results and class probabilities.
9. Evaluated the model using a confusion matrix and classification metrics.
10. Compared different classification thresholds.
11. Plotted the ROC curve and calculated AUC.
12. Tested the model with a new sample.

## 7. Model Evaluation
The model was evaluated using the following performance metrics:

- Accuracy
- Precision
- Recall
- Specificity
- F1-Score
- Confusion Matrix
- ROC Curve
- AUC Score

## 8. Conclusion
In this activity, Logistic Regression was implemented for binary classification using the Breast Cancer Wisconsin dataset. The model was trained and evaluated using different performance metrics. This activity helped in understanding classification, prediction probabilities, decision thresholds, and model evaluation.

**Note:** This is an educational machine learning activity and is not intended for actual medical diagnosis.
